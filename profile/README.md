# Betegna

Hospitality property management software for the teams that run properties.

Betegna brings core property workflows into one workspace, including guest stays, room operations, services and facilities, staff workflows, and reporting.

## Product status

Betegna is in active development. The hosted portal is a pre-release environment and may change as the product is built and tested; it is not a production service commitment.

## Technology

- Web application: React, TypeScript, and Vite
- API: NestJS and TypeScript
- Data: PostgreSQL with Prisma
- Authentication: Better Auth with server-side, role-aware authorization
- Delivery: Docker-based deployment support

The backend is authoritative for access control, property boundaries, and business rules. Application repositories are private; repository access is granted to project collaborators through the organization.
